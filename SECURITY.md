# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy leak in this project, please **do not** open a public issue.

1. Use [GitHub Security Advisories](../../security/advisories/new) to submit a confidential report.
2. Include steps to reproduce, affected versions, and any suggested mitigation.
3. Sensitive credentials, API tokens, and private logs should always be redacted before sharing.
