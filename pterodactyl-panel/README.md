## ⚙️ Configuration

Configure the app via the **Configuration** tab in the Home Assistant App page.

### Options

```yaml
app_url: http://pterodactyl.local
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
password: ''
ssl: false
```
